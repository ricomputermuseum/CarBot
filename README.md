# RICM-CarBot
This contains the Source code, Documentation, Bill of Materials, & 3D STL file for the CarBot from the Rhode Island Computer Museum. 
The code requires a Raspberry Pi Pico-W. Usually runs with a custom PCB that has two motor drivers and female headers that you can experiment with. 
The code is written for Micropython and you can use Thonny as the IDE. 

All software in the Software directory and lib/ of this repository needs to be copied to the Pico's root directory

Included is a Bill Of Materials (BOM) and a PDF for assembly and operation
